# Supabase Agent Skills Evaluation

**Reviewed:** 26 August 2026

The requested `npx skills add supabase/agent-skills` command is documented by Supabase as its official project-scope installation workflow. The available skills include the general **supabase** guide and **supabase-postgres-best-practices**, which is specifically required before PostgreSQL schema, migration, RLS, trigger, or restore changes.

The official guidance also requires verified work after each change, RLS on exposed schemas with explicit policies, no service-role key exposure in browser code, and current documentation review for Supabase behavior.
