# Lock Note-Inspired BugForge Visual System

BugForge adopts the **quiet confidence** of the Lock Note reference while retaining its own purpose: moving software issues from uncertain report to clear next action. The visual language is not a security-product imitation. It is an editorial workspace where every issue feels like a piece of carefully handled correspondence.

| Layer | Direction |
| --- | --- |
| Paper | Use `#F7F2EA` for the canvas, `#EFE5D7` for warm surfaces, and `#D8CDC0` for rules and folds. |
| Ink | Use `#1E1A18` for primary text and `#665D56` for supportive copy and metadata. |
| Signals | Use terracotta `#A55343` for decisive action, soft rose `#D8A097` for attention, sage `#75937E` for confirmed flow, and dusty gold `#C9A46A` for review states. |
| Typography | Cormorant-style serif display; DM Sans interface text; compact uppercase mono labels for issue metadata. |
| Detail | Fine correspondence rules, paper grain, folded corner shapes, restrained seal rounds, and generous white space. |
| Motion | Slow paper-slide and fade transitions; a seal pulse for key confirmation; no flashy movement or scroll-jacking. |

> **Design principle:** The workspace should make a bug feel easier to handle. It should never make it feel louder.
